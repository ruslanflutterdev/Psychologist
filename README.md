# Hero's Journey (Psychologist Web Panel)

Веб-приложение на Flutter для психологов и администраторов системы. Является панелью управления для детского мобильного приложения. Позволяет мониторить прогресс детей, управлять каталогом квестов и назначать задания.

## 🖥 Функциональность

Приложение предоставляет следующие возможности:

* **Панель Психолога (Dashboard)**:
    * Просмотр списка подопечных (детей).
    * Быстрый доступ к каталогам и настройкам.
* **Управление детьми (`ChildScreen`)**:
    * Детальная карточка ребенка (информация, архетип).
    * Просмотр назначенных и выполненных квестов.
    * **Назначение квестов**: Интерфейс для выбора заданий из каталога и назначения их конкретному ребенку.
* **Мониторинг прогресса (`ProgressScreen`)**:
    * Визуализация развития навыков (IQ, EQ, PQ, SOQ, SQ) с помощью радарных диаграмм (Radar Charts).
    * Аналитика выполнения заданий.
* **Каталог Квестов (`QuestsCatalogScreen`)**:
    * Полный CRUD (Создание, Чтение, Обновление, Удаление) квестов.
    * Фильтрация квестов по типам, активности и поиск по названию.
    * Активация/деактивация квестов.
* **Управление Ачивками (`AchievementsScreen`)**:
    * Создание и редактирование достижений, которые дети могут получить в мобильном приложении.
* **Аутентификация**: Вход, регистрация и восстановление пароля через Supabase Auth.

## 🛠 Технологический стек

* **Flutter Web** (SDK >=3.0.0)
* **Backend**: [supabase_flutter](https://pub.dev/packages/supabase_flutter) — используется та же база данных, что и в мобильном приложении.
* **State Management**: [flutter_bloc](https://pub.dev/packages/flutter_bloc) — управление состоянием (SessionCubit, LoginBloc, etc.).
* **Charts**: [fl_chart](https://pub.dev/packages/fl_chart) — построение графиков успеваемости и диаграмм сфер развития.
* **Web Specifics**:
    * `image_picker_web` — выбор изображений в браузере.
    * Адаптивная верстка под десктопные экраны.

## 📂 Структура проекта

Код организован в `lib/features/` и `lib/core/`:

* `core/` — Базовые сервисы (Supabase bootstrap, роутинг, темы).
* `features/`:
    * `auth_*/` — Модули авторизации (Login, Registration, Reset Password).
    * `psychologist_screen/` — Главный экран со списком детей.
    * `child_screen/` — Детальная страница ребенка и логика назначения квестов.
    * `quest_catalog/` — Управление библиотекой заданий.
    * `progress_screen/` — Экран с графиками и аналитикой.
    * `achievements/` — Управление достижениями.

## 🚀 Как запустить

Так как это веб-приложение, его лучше всего запускать в браузере (Chrome/Edge).

1.  **Клонируйте репозиторий:**
    ```bash
    git clone <your-repo-url>
    cd psychologist
    ```

2.  **Установите зависимости:**
    ```bash
    flutter pub get
    ```

3.  **Настройка Supabase:**
    Ключи инициализации находятся в `lib/main.dart`. Убедитесь, что URL и Anon Key совпадают с теми, что используются в мобильном приложении, чтобы данные синхронизировались.

4.  **Запуск:**
    ```bash
    flutter run -d chrome
    ```

## 📝 Взаимодействие с Students App

Это приложение работает в паре с мобильным клиентом.
1.  **Психолог** создает квест в *Web Panel*.
2.  **Психолог** назначает квест ребенку через *Child Screen*.
3.  **Ребенок** видит новый квест в своем мобильном приложении, выполняет его и отправляет отчет.
4.  **Психолог** видит обновленный прогресс (XP и уровни сфер) на графиках в *Web Panel*.
